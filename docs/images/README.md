# Screenshot Aplikasi

Simpan screenshot aktual aplikasi pada direktori ini dengan nama:

- `login.png` — screenshot halaman login.
- `dashboard.png` — screenshot dashboard setelah login.

Kedua file tersebut digunakan oleh bagian **Preview Aplikasi** pada `README.md`.

Gunakan gambar yang jelas, potong bagian browser yang tidak diperlukan, dan pastikan tidak ada password, token, atau data pribadi yang terlihat.
